# ВНосКино (TorrentTV)

Открытое приложение для Android TV 10+: поиск фильмов и сериалов, каталоги
(TMDB), стриминг с торрентов (jlibtorrent), избранное и «Продолжить просмотр».

## Структура

- `app/` — модуль приложения (Kotlin + Compose for TV)
- Минимальная версия: **Android TV 10 (API 29)**, целевая: 34

## Хранение скачанного

Фильмы качаются во внутреннее хранилище приложения
(`files/downloads/{тип}-{id}/`) и **удаляются автоматически при выходе
из плеера** — место не забивается. Пересмотр = повторная загрузка.

## Провайдеры автопоиска раздач

| Провайдер | Ключи/настройка | Что ищет |
|---|---|---|
| apibay (ThePirateBay) | ничего не нужно | всё, по названию |
| Torrentio | ничего не нужно (нужен IMDb id у карточки) | фильмы |
| Jackett | URL сервера + API-ключ в «Настройках» | всё, по всем вашим индексерам |

Результаты сливаются, дедуплицируются по info_hash и сортируются по сидам.
На экране автопоиска — скраббер: чипы качества 2160p / 1080p / 720p / SD.

Частные трекеры (RuTracker, Kinozal и т.п.) подключаются через Jackett:
его веб-интерфейс хранит их учётные данные, приложению нужны только
адрес и API-ключ.

## Сборка

```bash
./gradlew assembleDebug          # отладочный APK
./gradlew installDebug           # установка на подключённое ТВ/эмулятор (adb)
```

## Ветки и обновления

```
main ──► test ──► release
         │         │
         ▼         ▼
  CI: unit-тесты   CI: сборка APK → GitHub Release
                   ▼
  приложение на ТВ проверяет Releases API и
  само предлагает установку новой версии
```

- **`test`** — все тесты и проверочные сборки (workflow `tests.yml`)
- **`release`** — мердж сюда триггерит сборку и публикацию релиза (`release.yml`);
  перед мерджем нужно поднять `versionName` в `app/build.gradle.kts` — из него
  делается тег ` vX.Y.Z` и APK-ассет
- Приложение при старте сравнивает `versionName` с последним GitHub Release
  и при наличии более новой версии предлагает скачать и установить обновление
