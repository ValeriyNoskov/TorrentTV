Механика:
1. Над каталогом — кнопки Жанр · Тип · Страна · Год · Рейтинг (с бейджем количества выбранных).
2. Кнопка → своя компактная модалка: поиск сверху (в фокусе), ниже список с галочками; ↑↓ листает, ОК — галочка.
3. Поиск матчит подстроку: в «Годе» набрал «202» → список сразу 2020…2026; «кор» в странах → Великобритания, Корея.
4. «Применить» → модалка закрывается, над каталогом появляется строка включённых фильтров (бейджи с ✕ — убрал один, снялся только он; «очистить всё»).
5. Каталог фильтруется сразу при выставлении галочек — модалка поверх, результат виден по краям.
