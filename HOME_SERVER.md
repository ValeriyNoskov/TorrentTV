# Домашний медиасервер для ВНосКино

> Инструкция: как снять нагрузку с телевизора, держа TorrServer (и библиотеку)
> на отдельном устройстве. Телевизор становится чистым плеером: не греется,
> не тратит память, тяжёлые 4K идут ровнее.
>
> ВНосКино уже умеет работать с внешним сервером: ⚙ → **TorrServe** →
> вписать адрес `http://<IP-сервера>:8090`. Больше ничего менять не нужно.

---

## ✅ Уже настроено: MacBook Air (192.168.3.78)

TorrServer установлен и работает как сервис launchd (переживает падение и
перезагрузку), сон отключён.

| Что | Значение |
|---|---|
| Адрес для ВНосКино | `http://192.168.3.78:8090` |
| Где установлен | `~/torrserver/torrserver` (MatriX.147.1, darwin-amd64) |
| Автозапуск | `~/Library/LaunchAgents/ru.torrserver.plist` (`ru.torrserver`) |
| Лог сервера | `~/torrserver/torrserver.log` |
| Сон | отключён (`pmset -a sleep 0`, `womp 1`) |
| Пользователь | `valeriy` |

Управление (по SSH с рабочего Mac):

```bash
ssh -i ~/.ssh/id_ed25519_vnoskino Valeriy@192.168.3.78
launchctl kickstart -k gui/$(id -u)/ru.torrserver   # перезапуск
launchctl bootout gui/$(id -u)/ru.torrserver        # остановить
curl -s http://127.0.0.1:8090/echo                  # проверка (ответ: MatriX.147.1)
```

Два нюанса, проверенные на практике:

- **Флаги запуска — короткие**: `-d` (каталог), `-p` (порт), `-l` (лог).
  С `-dir/-port` сервер молча выходит с кодом 2, и launchd показывает
  `state = spawn scheduled`.
- **Автовход**: агент launchd стартует только после входа пользователя в
  систему. Чтобы сервер поднимался после перезагрузки без участия человека,
  включите «Системные настройки → Пользователи и группы → Автоматический вход».

## Вариант 1: Mi Box (самый быстрый старт, 5 минут)

TorrServer ставится прямо APK-файлом.

1. **Mi Box** → Настройки → Безопасность → разрешить **установку из неизвестных
   источников** (для файлового менеджера).
2. Скачать APK: `github.com/YouROK/TorrServer/releases` →
   - **Mi Box S / Mi Box 4 / новее** → `TorrServer-android-arm64.apk`
   - **старые Mi Box 3C / первый S** → `TorrServer-android.apk`
   Скачать можно браузером бокса или перекинуть с флешки.
3. Установить, запустить — сервер поднимется на порту **8090**.
   В настройках TorrServer включить **автозапуск**.
4. Узнать IP бокса: Настройки → Сеть и интернет → будет вида `192.168.1.45`.
5. **Телевизор** → ВНосКино → ⚙ → TorrServe → вписать
   `http://192.168.1.45:8090` (ваш IP бокса).

**Нюансы:**
- Настройки → Сеть → **«Не отключать Wi-Fi в спящем режиме»** — иначе сервер
  пропадает, когда бокс засыпает.
- Внутренней памяти бокса (~8 ГБ) хватает: TorrServer кеширует только
  просматриваемые куски и чистит сам.
- Внешний диск лучше с **внешним питанием** (USB бокса слабый), формат **exFAT**.

## Вариант 2: MacBook Air (и любой Mac) — с библиотекой «как Netflix»

TorrServer (торренты) + Jellyfin (библиотека с постерами и прогрессом на всех
устройствах). Ставится за ~30 минут.

### Шаг 1. Установка серверов

```bash
# TorrServer: бинарь с github.com/YouROK/TorrServer/releases
# файл TorrServer-darwin-amd64 → переименовать в torrserver
chmod +x torrserver
mkdir -p ~/torrserver-data && ./torrserver -d ~/torrserver-data -p 8090

# Jellyfin: библиотека с постерами (опционально, но приятно)
brew install jellyfin        # или .pkg с jellyfin.org/downloads
```

Jellyfin веб-интерфейс: `http://localhost:8096` — добавить папку с фильмами.

### Шаг 2. mac не должен засыпать

```bash
sudo pmset -a sleep 0          # не спать никогда (при питании от сети)
sudo pmset -a womp 1           # пробуждение по сети
```

Или через Системные настройки → Экран/Энергосбережение.
Закрытая крышка с подключённым питанием = обычный режим работы (clamshell),
нагрева нет: стрим без транскодирования почти не грузит CPU.

### Шаг 3. Автозапуск после перезагрузки

Системные настройки → Основные → Объекты входа → добавить:
- `torrserver` (скрипт запуска с флагами выше)
- Jellyfin (если ставили .pkg — сервис уже сам)

### Шаг 4. Подключить телевизор

- **ВНосКино** (ТВ/Mi Box): ⚙ → TorrServe → `http://<IP-мака>:8090`
- **Jellyfin-клиент**: на TCL (Android TV) и Mi Box — приложение Jellyfin
  из магазина; на телефоне — тоже Jellyfin. Войти по адресу мака.

### Нюансы

- Диск: формат **exFAT** — читается и Mac, и Android.
- 4K HEVC клиенты (TCL/Mi Box) переваривают сами (direct play). Транскод
  на Air 2017 потянет только 1080p — практически не понадобится.
- IP мака лучше закрепить в роутере (DHCP-резервация), чтобы адрес не менялся.

## Что получает телевизор

- ВНосКино качает/стримит через сервер — ТВ только рисует картинку.
- «Продолжить просмотр», история и настройки остаются в приложении как были.
- При недоступности сервера верните адрес обратно на `http://127.0.0.1:8090`
  (встроенный режим) — всё заработает по-старому.

## Типовые проблемы

| Симптом | Причина / решение |
|---|---|
| «TorrServe не ответил» | Не тот IP, сервер не запущен, бокс уснул → проверить `http://<IP>:8090` в браузере |
| Фильм буферизуется | Медленная раздача (мало сидов) — выберите другую в списке; проверьте, что Mac/бокс не по Wi-Fi 2.4 ГГц |
| «Пакет конфликтует…» | На ТВ: не тот APK-подписи — скачивайте только с GitHub-релизов ВНосКино |
| TorrServer пропадает после сна | «Не отключать Wi-Fi в спящем режиме» / `pmset -a sleep 0` |
